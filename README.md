# DevOps 30-Minute Learning Log

This repository documents a hands-on DevOps learning journey through short, practical exercises. Each session records what was built or configured, the commands used, problems encountered, lessons learned, and a suggested next step. The repository is a collection of learning exercises and evidence—not one integrated application.

## Current progress

The latest documented session is **November 2, 2026**. It used Minikube and the Kubernetes CLI to create a sample deployment, expose it as a NodePort service, and access it locally. The session notes Minikube startup troubleshooting as a learning point.

The learning path has covered:

- Building and containerizing Java Spring Boot, Next.js, full-stack, Flask/MySQL, Node.js, Python, TensorFlow, and PyTorch examples
- Running JupyterLab and Apache Airflow with Docker and Docker Compose
- Installing `kubectl`, setting up Minikube, and inspecting a local Kubernetes cluster
- Deploying and accessing an application through Kubernetes

**Next documented step:** deploy a LoadBalancer using the Kubernetes CLI. Progress here reflects the latest session log in the repository; check the dated notes for the full history.

## Repository layout

- [`notes/`](notes/) — dated session logs, including outcomes, troubleshooting, takeaways, and next actions
- [`tasks/`](tasks/) — exercise files, configurations, and screenshots associated with sessions

The dated folders under `notes/` and `tasks/` are organized by month and session date. Some exercises include their own README or run instructions; use those when working with an individual example.

## Session log format

Each log captures the session date and topic, completed work, commands and configuration, problems and their causes, takeaways, and the next action. Start with the [latest log](notes/November-2026/2-November-2026.md) to see the current documented stopping point.
